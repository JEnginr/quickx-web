Primary-location safety checks
------------------------------
PASS - Existing primary CR_PART_LOCATION must be Active, unlocked and non-transit.
PASS - HOLD is not accepted as an automatic primary destination.
PASS - A missing part/location row can still use PART.PRIMARY_LOC_ID so RF Plus may validate/create it.
PASS - RF Plus-rejected destinations are marked Needs Location and cannot be silently resubmitted.
PASS - A missing location is not replaced with the only non-primary suggestion.

Design preservation checks
--------------------------
PASS - No global theme, navigation, spacing, table or popup stylesheet was changed.
PASS - Button-color changes are isolated inside the native Inventory Adjust Shadow DOM.
PASS - LAN one-click hosting behaviour remains unchanged from v0.2.

Limitations
-----------
- Live production Adjust In/Adjust Out transactions were not submitted during build testing.
- Native browser datalist option colors can vary by browser; the selected primary value and Primary badge remain visibly yellow.
- First acceptance should use one small known Adjust In and one existing Adjust Out before mass processing.
